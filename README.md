# AI Resume Analyzer & Interview Preparation Platform

A Production-ready full stack GenAI platform for resume analysis, ATS optimization, skill-gap detection, and AI-powered interview preparation.

## Tech Stack

**Frontend**

- Next.js
- Tailwind CSS

**Backend**

- Node.js
- Express.js
- MongoDB
- Mongoose

**Authentication**

- JWT (Access & Refresh Tokens)
- Session-Based Authentication
- Token Blacklisting
- OTP Email Verification

**AI & PDF**

- Gemini API
- Puppeteer

## Features

- Secure JWT & OTP authentication
- Resume upload and analysis
- Job description matching
- ATS resume optimization
- AI skill-gap detection
- Personalized interview question generation
- PDF resume generation

## Goal

Build a scalable, production-grade AI job preparation platform using modern full stack architecture and generative AI.
